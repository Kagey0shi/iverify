# iVerify

Dashboard for Ghana identity verification, by ShrinQ Limited.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

P0 screens: Dashboard home and Verify. History, Billing, Settings, and API Docs are stubs.

Sandbox test IDs on Verify: `GHA-291847365-1` (match), `GHA-000000000-0` (no match), `GHA-999999999-9` (error).

Dashboard demo query params: `?status=degraded|outage` and `?empty=1`.
